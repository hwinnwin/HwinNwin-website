# Replit Build Prompt — **hwinnwin.com** (Ethos + Design Codex)

**Goal:** Build a clean, fast, accessible landing site for **hwinnwin.com** that presents our **Ethos** and **Design Codex**. The site should feel like a sacred-tech scroll: timeless, gentle, visionary. Output production‑ready HTML/CSS/JS (or a minimal React/Vite), with responsive design, semantics, and basic SEO.

---

## 1) Brand Tone & VYBE
- **Voice:** warm-but-laid-back, grounded honesty, light dry wit. Sacred-tech, not preachy.
- **Keywords:** remembering, coherence, frequency, precision, presence.
- **Mantras:** “The goal is always 100%.” “Aim for 100; settle at 99.99%.”
- **Spelling rule:** always write **VYBE** (never “vibe”).

---

## 2) Visual Direction
- **Aesthetic:** scroll-like layout, generous breathing room, elegant typography, subtle motion (fade/pulse/wave on scroll).
- **Palette (suggested):** deep indigo (#0E1330), near-black (#0A0D1A), silver-white (#E6E9F2), soft aura accents (#A7B6FF, #B4FFE7). Keep contrast AA+.
- **Typography:**
  - Headings: a refined serif or display (e.g., "Fraunces"/"Cormorant").
  - Body/UI: a clean sans (e.g., "Inter"/"Suisse Intl"-style).
  - Use varied sizes; hero H1 large; codex items 1–2 lines each.
- **Motion:**
  - On-scroll reveal (opacity + slight translateY).
  - Gentle, not distracting.
  - Reduce motion if `prefers-reduced-motion`.

---

## 3) Site Structure
- **Header:** minimal logo (text lockup: *hwinnwin*), right-aligned nav (Ethos, Codex, Contact/CTA).
- **Hero:** concise line + CTA.
- **Section 1 – Ethos (Creation Philosophy):** 4–6 short paragraphs.
- **Section 2 – Design Codex:** list of 10 mantras with micro-descriptions.
- **Section 3 – Call to Action:** clear next step (newsletter, contact, or pilot offering).
- **Footer:** links, ©, minimal socials (optional), email.

## 5) Layout & Components (Acceptance Criteria)
- **Header:** sticky, blur background on scroll; active link state.
- **Hero:** full-viewport height on desktop, comfortable stack on mobile; H1, lead, CTA button.
- **Ethos Section:** max-width readable column (~70ch), generous line-height; subtle divider.
- **Codex Grid:** responsive 2–3 column grid on desktop; single column on mobile; each item as a card with soft shadow, rounded-2xl, ample padding.
- **CTA Section:** centered stack, strong contrast button; `mailto:` works cross-platform.
- **Footer:** small type, high contrast, links accessible.

---

## 6) Accessibility
- Meet WCAG 2.1 AA contrast ratios.
- Semantic HTML: <header>, <main>, <section>, <nav>, <footer>, proper headings.
- Focus-visible styles; keyboard navigable; skip-to-content link.
- Respect `prefers-reduced-motion`.
- Alt text for any non-decorative SVGs.

---

## 7) Performance & SEO
- Ship lean: no large frameworks unless using minimal React/Vite. Inline critical CSS or small CSS file.
- Meta: title (50–60 chars), description (≤160 chars), OpenGraph/Twitter tags.
- Favicon + social preview.
- Lighthouse ≥ 95 on Performance, Accessibility, Best Practices, SEO.

**Suggested Meta:**  
- **Title:** HWINNWIN — Remembering, by design.  
- **Description:** Ethos and Design Codex for building from coherence — language, code, and consciousness woven as one.

## 8) Tech Notes (Implementation Options)
- **Option A (Static):** Single `index.html` + `styles.css` + light `script.js` for reveal effects.
- **Option B (Vite React):** Small component set (Hero.jsx, Ethos.jsx, Codex.jsx, CTA.jsx, Header.jsx, Footer.jsx). Use Tailwind or handcrafted CSS.
- **Animations:** IntersectionObserver + CSS transitions (opacity/translate). No heavy libs.
