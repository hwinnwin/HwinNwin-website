Alright, here’s the **next evolution:** a GitHub Actions add-on that
1️⃣ comments Lighthouse report links directly on Pull Requests, and
2️⃣ **blocks merges** unless the Go-Live + Lighthouse jobs pass.

---

### 🧩 1) Update your workflow file

Replace the top of `.github/workflows/phase2.yml` with this (or merge it in):

```yaml
name: Phase II — Go-Live & Lighthouse

on:
  push:
    branches: [ "main" ]
  pull_request:
    branches: [ "main" ]
  workflow_dispatch:

permissions:
  contents: read
  pull-requests: write   # 👈 needed for comment bot
```

Everything else in the file stays the same.

---

### 💬 2) Add the PR comment step

Drop this **after** the `Upload Lighthouse Reports` step inside the `lighthouse` job:

```yaml
      - name: Comment summary on PR
        if: github.event_name == 'pull_request'
        uses: marocchino/sticky-pull-request-comment@v2
        with:
          header: Lighthouse Report
          message: |
            🚀 **Phase II Validation Complete**

            ✅ Go-Live + Lighthouse checks ran for this PR.

            📊 [Download the Lighthouse HTML reports from “Artifacts”](https://github.com/${{ github.repository }}/actions/runs/${{ github.run_id }})

            _(Performance must stay ≥ 90 to merge)_
```

This adds an auto-updating comment with your results every time the workflow runs on a PR.

---

### 🔒 3) Enforce pass-to-merge

Go to
**GitHub → Settings → Branches → main → Branch protection rules → Edit**

Enable:

* ☑️ **Require status checks to pass before merging**
* Then tick both workflow jobs:

  * `validate`
  * `lighthouse`

Now no one (even you 😏) can merge unless all sacred metrics are green.
