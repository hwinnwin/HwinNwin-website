If you want to deploy your Replit site to **[www.hwinnwin.com](http://www.hwinnwin.com)**, here’s exactly how to do it safely and cleanly:

---

### 🌍 **1. Add Your Custom Domain in Replit**

1. Open your project in Replit.
2. Click **Deploy → Manage Domains** (or the globe icon).
3. Enter:

   ```
   www.hwinnwin.com
   ```
4. Replit will show you **two DNS records** — one or more `A` and `CNAME` targets. Copy those values.

---

### 🧭 **2. Update DNS at Your Domain Registrar**

At the registrar where you bought **hwinnwin.com** (GoDaddy, Namecheap, Google Domains, Cloudflare, etc.):

| Type  | Name / Host | Value                                                    | TTL  |
| ----- | ----------- | -------------------------------------------------------- | ---- |
| CNAME | www         | (Replit’s CNAME target)                                  | Auto |
| A     | @           | (Replit’s A-record IP address, usually `35.186.238.101`) | Auto |

*(If Replit only gives a CNAME for www, keep @ pointing to your existing root provider or set a redirect from root → [www](http://www).)*

Save your changes and wait a few minutes for DNS to propagate.

---

### 🔐 **3. Verify and Issue SSL**

Back in Replit → Deploy → Manage Domains → click **Verify**.
When the DNS is correct, Replit will automatically issue an SSL certificate for **[https://www.hwinnwin.com](https://www.hwinnwin.com)**.

---

### ⚙️ **4. Set `VITE_BASE_URL` (optional but recommended)**

In Replit → Secrets:

```
VITE_BASE_URL=https://www.hwinnwin.com
```

That helps your sitemap, OG tags, and analytics pick up the right domain.

---

### 🚀 **5. Redeploy**

Click **Deploy → Production** again.
Once it builds, your live URL will read:

> ✅ [https://www.hwinnwin.com](https://www.hwinnwin.com)

---

### 🧘‍♂️ **6. Post-Deployment Verification**

Test:

```
https://www.hwinnwin.com/
https://www.hwinnwin.com/hwin
https://www.hwinnwin.com/blog/lumen-ascends
https://www.hwinnwin.com/sitemap.xml
https://www.hwinnwin.com/robots.txt
```

If all load without redirects or SSL errors → you’re fully ascended.
