### 1) Privacy-first Analytics (Plausible, consent-gated)

**Files to add:**

* `client/src/lib/analytics/plausible.ts`
* `client/src/lib/cookies/consent.ts` (use or extend existing if present)
* `client/src/hooks/useConsent.ts`

**Implement:**

* Add env toggle: `VITE_ANALYTICS_PROVIDER="plausible"`, `VITE_PLAUSIBLE_DOMAIN="hwinnwin.com"` (or the current domain).
* In `plausible.ts`, export:

  * `loadPlausible(domain: string)` → inject `<script async defer data-domain="..." src="https://plausible.io/js/script.js">`.
  * `track(event: string, props?: Record<string, any>)`.
* In `consent.ts`:

  * `getConsent()`, `setConsent()`, `onConsentChange(cb)`, `CONSENT_VERSION = "2025.10.25.v1"`.
  * Categories: `essential` (locked true), `preferences`, `analytics`, `marketing`. Persist to `localStorage: cookiePreferences`.
  * If `navigator.doNotTrack === "1"`, force non-essential false.
* In app bootstrap (`client/src/main.tsx` or equivalent):

  ```ts
  import { getConsent, onConsentChange } from "@/lib/cookies/consent";
  import { loadPlausible } from "@/lib/analytics/plausible";

  function maybeInitAnalytics() {
    const prefs = getConsent();
    if (prefs?.analytics) {
      const domain = import.meta.env.VITE_PLAUSIBLE_DOMAIN;
      if (domain) loadPlausible(domain);
    }
  }

  maybeInitAnalytics();
  onConsentChange(() => window.location.reload());
  ```
* **QA**: On first load, no analytics script present. After user opts into “Analytics” in cookie modal, script appears on next navigation/reload.

**Plausible loader (plausible.ts):**

```ts
export function loadPlausible(domain: string) {
  if (document.querySelector('script[src*="plausible.io/js/script.js"]')) return;
  const s = document.createElement("script");
  s.async = true;
  s.defer = true;
  s.dataset.domain = domain;
  s.src = "https://plausible.io/js/script.js";
  document.head.appendChild(s);
}

export function track(event: string, props?: Record<string, any>) {
  // @ts-ignore
  window.plausible?.(event, { props });
}
```
